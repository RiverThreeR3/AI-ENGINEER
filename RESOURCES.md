# Validated Open-Source Learning References

## Primary curriculum — required reference

**[rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)** is the canonical upstream curriculum (MIT). Use its exact published lessons, study/project tutor contracts, the [Applied AI Engineer career route](https://github.com/rohitg00/ai-engineering-from-scratch/blob/main/learning-paths/applied-ai-engineer.json), and interview bank.

- [Curriculum-to-portfolio mapping](docs/COURSE_MAPPING.md)
- [Daily learning and delivery workflow](docs/DAILY_WORKFLOW.md)

The public course is **not** this repository's implementation or proof of a learned skill. Verify permissions and required attribution before adapting any source code.
